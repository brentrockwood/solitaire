# Solitaire Game Build

I like the game [Solitaire Epic](/Applications/Solitaire\ Epic.app) but it has some deficiencies. I would like to build our own. Use the [rea tool](https://github.com/morluto/rea) if you want. 

## Requirements

### Must have

- Copy the scoring systems exactly.
- Vegas cumulative would be a nice to have option. If so, it would also need the reset function.
- I use the "Undo" function.
- I always use left-handed mode.

### Must not have

- No Privacy policy.
- No accounts.
- No credits.
- No "Our Games!"
- No "Help"
- No GameCenter.
- No goals.
- No "in-game" full-screen option. It should use native OS affordances.
- No "in-game" quit option. It should use native OS affordances.
- For some reason it stops the screensaver from displaying. I do not want this functionality.

### Non-functional requirements

- Startup and especially shutdown can be very slow in the existing game. Should be fast.
- Low resource consumption is important to me.

### Nice to have

- The cards themselves look nice already. Don't need millions of options. I just choose a plain style.
- The rest of the UI I don't really care about so long as it looks nice and "Mac-like".
- Finish animation. Doesn't have to look the same.
- Sound.
- Optional time/moves.
- Show/hide menu is not important. So long as I can access all the functions.
